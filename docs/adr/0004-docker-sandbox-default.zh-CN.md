# ADR 0004：非测试环境默认使用 Docker Sandbox

- 状态：已接受
- 日期：2026-09-13

## 背景

Agent 可能生成并执行任意代码。如果直接在 Gateway 或 Worker 进程中执行，会获得：

- 进程环境变量；
- 工作区文件；
- 网络权限；
- 应用依赖；
- Worker 进程生命周期。

这属于不可接受的安全边界。

## 决策

开发和生产的正式执行使用 Docker Sandbox Provider。测试使用 Local Sandbox，以获得确定性和较低启动成本。

Docker Sandbox 规则：

- 非 root 数字用户；
- 只读根文件系统；
- CPU、内存和 PID 限制；
- 默认禁用网络；
- 独立挂载工作目录；
- 执行超时；
- 节点结束后删除容器；
- 容器标签关联 `run_id` 和 `node_run_id`。

## 影响

### 正面

- Agent 代码不直接接触 Gateway 或 Worker 进程权限。
- 资源上限和网络策略可以显式控制。
- 容易在演示中证明隔离边界。

### 代价

- Worker 必须能够访问 Docker Engine。
- 首次运行需要拉取基础镜像。
- 需要额外处理宿主机与容器网络下的工作区路径映射。
- 需要显式开启依赖网络的代码执行。
